In-game settings and common issues

  • FOV: Escape → Mod Config → Simple FOV Slider.
  • Scrapping confirmation: MCM → FallUI Confirm Boxes.
  • Pip-Boy display issues: MCM → Baka Fullscreen Pipboy; try disabling the main option.
  • Temporary invulnerability after workshop flight: Re-enter Workshop Mode, wait briefly, then exit.
  • Achievements: Enabled, per the author.

Version notes

Based on the author's September 25, 2026 v9.5.1 changelog and current FAQ. The list runs Fallout 4 1.10.163 through Wabbajack's stock-game downgrade. Survival Mode is unsupported.

Verified setup and gameplay notes for v9.5.1

Anniversary Edition clarification: The author's FAQ specifies that Magnum Opus runs the downgraded 1.10.163 runtime. Even if Steam installs a newer Fallout 4 release (including 1.11.240), Wabbajack builds a separate downgraded Stock Game. Do not assume that F4SE plugins requiring 1.11.240 are compatible with Magnum Opus. Official installation instructions · Runtime FAQ.

MCM preset: The author's post-installation instructions direct players to open Esc → MCM Config and apply Opus v9 after leaving Vault 111. The v9.5.1 changelog says this preset was changed to enable Workshop Mode flight. The preset's full configuration file has not been independently inspected.

Sim Settlements 2 prebuilt settlements: The author recommends that first-time SS2 players not enable automatic prebuilt settlements. Enabling them can make ownership and manual rebuilding less straightforward. The author recommends excluding Starlight Drive-In if you want to build there yourself. These are author recommendations, not mandatory rules. Source: post-installation guide.

Power armor repairs: The official FAQ says to craft Power Armor Repair Kits at the Engineering Workbench or purchase them from vendors such as the Atom Cats and Brotherhood of Steel. Source: FAQ.

September 2026 gameplay changes

  • Version 9.5.1 removed the ability to craft bandages and morphine injectors.
  • Version 9.5.1 changed Visible Favorites to display equipped favorites by default, though the author notes existing settings might not transfer consistently.
  • Version 9.5.0 removed Survival Mode overhaul components and ended support for Survival Mode.
  • Version 9.5.0 requires a new save.
